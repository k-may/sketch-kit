# Sketch Kit website

Static Astro site for [Sketch Kit](https://github.com/k-may/sketch-kit). The narrative, markup, and links render as HTML. The iteration demo is a small Lit Web Component loaded only in its section.

```sh
cd website
npm install
npm run dev
npm run build
```

Astro writes the deployable site to `website/dist/`. The demo illustrates the copy/change/compare workflow; it does not execute user code or invoke the Sketch Kit CLI.
